# Methodology

1. Profile raw files for missing values, duplicates, invalid numeric values and inconsistent text.
2. Standardize text and remove duplicate keys.
3. Reject invalid operational records rather than silently changing them.
4. Recalculate treatment cost from quantity × unit cost.
5. Create analyst-friendly derived fields such as new/returning, high-cost, readmission and operational priority.
6. Validate referential integrity and negative-value rules.
7. Analyze the cleaned data in Excel, SQL and Power BI.
