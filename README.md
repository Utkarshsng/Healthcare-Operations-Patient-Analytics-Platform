# Healthcare Operations & Patient Analytics Platform — Beginner Edition

A portfolio-ready, fully synthetic healthcare operations analytics project built for Data Analyst / BI Analyst roles.

## Dataset scale
- 2,000 patients
- 30 doctors
- 8 departments
- 8,000 encounters
- 12,000 treatments
- 15,000 appointments
- 2023–2025

## Tech Stack
Python, Pandas, NumPy, Excel, Power Query, SQL, Power BI, DAX

## Workflow
Raw Data → Python/Power Query Cleaning → Validation → Excel → SQL → Star Schema → DAX → Power BI → Insights → Recommendations

## Important
All data is synthetic and anonymized. It contains no real patient information. Operational priority flags are rule-based analytics examples only and are **not clinical decision-making tools**.

## Dashboard Pages
1. Executive Operations Overview
2. Patient & Encounter Intelligence
3. Appointment & Department Operations
4. Cost, Readmission & Priority Analysis


## Patient-level reporting
`patient_id` is the analytical key, while `patient_name` is used for readable reporting in Excel, SQL and the Power BI patient detail table.
